# 合成大白快乐游戏

“合成大白快乐游戏”是一个零依赖的网页版合成小游戏，可直接运行在桌面浏览器、手机浏览器和 GitHub Pages 上。

## 直接试玩

在这个目录打开 PowerShell，执行：

```powershell
python -m http.server 8080
```

然后用浏览器访问：

```text
http://localhost:8080
```

也可以直接双击 `index.html` 试玩。用本地服务器打开时，图片和音频资源的加载行为更稳定。

## 操作

- 按住游戏区域并左右拖动，松开后投放。
- 电脑端可用鼠标移动瞄准，也可以使用方向键移动、空格投放。
- 两个同级角色相撞后会合成下一级。
- 两个最高级角色相撞会一起消除，并获得额外 100 分。
- 角色停在危险线上方约 1.45 秒后游戏结束。

## 放置你的图片

图片放在：

```text
assets/images/
```

请使用下面的文件名。全部为可选文件，缺失时会自动使用程序绘制的圆形占位角色。

| 文件名 | 等级 | 当前角色 | 图片尺寸 |
|---|---:|---|---:|
| `fruit-01.png` | 1（最小） | 急救包 | 512 × 512 |
| `fruit-02.png` | 2 | 弹药包 | 512 × 512 |
| `fruit-03.png` | 3 | 霰弹枪 | 512 × 512 |
| `fruit-04.png` | 4 | 突击步枪 | 512 × 512 |
| `fruit-05.png` | 5 | 盾牌干员 | 512 × 512 |
| `fruit-06.png` | 6 | 报纸勇士 | 512 × 512 |
| `fruit-07.png` | 7 | 大白 | 512 × 512 |
| `fruit-08.png` | 8 | 大白出击 | 512 × 512 |
| `fruit-09.png` | 9 | 婚纱干员 | 512 × 512 |
| `fruit-10.png` | 10（最大） | 双萃大白 | 512 × 512 |

图片要求：

- 当前十张图片已经放入对应位置，并统一裁剪成 512 × 512 的圆形透明 PNG。
- 角色主体居中，四周尽量留出少量透明边距。
- 画面接近正方形，人物或水果不要贴边。
- 等级越大，游戏中的碰撞半径也越大，但图片可以保持相同像素尺寸。
- 以后替换同等级图片时，把同名文件放进目录后刷新页面即可，不需要修改代码。

如果只想替换部分等级，也是可以的。未提供图片的等级仍会显示程序绘制的占位角色。

游戏中的角色图片、圆形遮挡区域和物理碰撞体使用同一个半径，因此画面中的圆直径就是实际碰撞直径。

## 放置你的音效

音效放在：

```text
assets/audio/
```

| 文件名 | 播放时机 |
|---|---|
| `drop.mp3` | 投放角色 |
| `merge.mp3` | 合成成功 |
| `bonus.mp3` | 两个最高级角色消除 |
| `game-over.mp3` | 游戏结束 |

建议每个音效控制在 0.1–1.2 秒，使用 44.1 kHz 或 48 kHz 的 MP3。文件缺失时，游戏会自动使用 Web Audio 生成的提示音。

## 修改角色名称和大小

打开 `game.js`，在开头的 `FRUITS` 数组中修改：

```js
const FRUITS = [
  { name: "莓莓", r: 14, color: "#ef6882", light: "#ffb3c0", dark: "#c94461" },
  // ...
];
```

- `name`：结算和无障碍提示中显示的名称。
- `r`：物理碰撞半径。
- `color`、`light`、`dark`：没有图片时占位角色使用的颜色。

如果以后使用 WebP 图片，需要在 `game.js` 的 `IMAGE_PATHS` 中把 `.png` 改为 `.webp`。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 把 `outputs/suika-game` 里面的所有文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 在仓库的 **Settings → Pages** 中选择从主分支根目录发布。
4. 等待 GitHub 生成公开访问地址。

资源目录、文件名和脚本已经按静态网页方式组织，不需要构建步骤。
